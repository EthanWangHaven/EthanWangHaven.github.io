## 环境准备

### Node.js 安装（Windows）

博客基于 Next.js 16，需要 Node.js 18.18+ 环境：

- 从 [Node.js 官网](https://nodejs.org/) 下载 LTS 版本安装包
- 安装时勾选 "Add to PATH"，安装后验证：

```powershell
node --version
npm --version
```

### 创建项目

```powershell
cd C:\Users\ethan.wang18\Desktop\my-blog
npx create-next-app@latest my-blog-next --typescript --tailwind --app --eslint
cd my-blog-next
```

### 安装核心依赖

```powershell
npm install gray-matter next-mdx-remote remark-gfm remark-math rehype-katex rehype-slug rehype-autolink-remark-heading-id next-themes lucide-react motion
```

| 依赖 | 用途 |
|------|------|
| `gray-matter` | 解析 MDX 文件 frontmatter |
| `next-mdx-remote` | 服务端渲染 MDX 内容 |
| `remark-gfm` | GitHub Flavored Markdown（表格、任务列表等） |
| `remark-math` + `rehype-katex` | LaTeX 数学公式渲染 |
| `rehype-slug` + `rehype-autolink-remark-heading-id` | 标题自动生成锚点 |
| `next-themes` | 亮/暗主题切换 |
| `lucide-react` | 图标库 |
| `motion` | 动画（Framer Motion） |

## 绑定 GitHub 仓库并推送

```powershell
cd C:\Users\ethan.wang18\Desktop\my-blog\my-blog-next

# 初始化 Git 仓库
git init

# 关联远端仓库
git remote add origin https://github.com/EthanWangHaven/EthanWangHaven.github.io.git

# 分支重命名为 main
git branch -M main

# 添加所有文件
git add .

# 提交
git commit -m "重构博客为 Next.js 16 项目"

# 推送到 GitHub
git push -u origin main --force
```

> `--force` 会覆盖远程历史，仅在首次初始化新仓库时使用。

## 配置 GitHub Actions 自动部署

在项目根目录新建 `.github/workflows/deploy.yml`：

```yaml
name: Build & Deploy Next.js Blog
on:
  push:
    branches: [main]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: false
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v4
      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - name: Install dependencies
        run: npm ci
      - name: Build static site
        run: npm run build
      - name: Upload pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./out
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

> 需要在 `next.config.ts` 中添加 `output: "export"` 以生成静态导出文件。

## GitHub 后台开启 Pages

1. 打开仓库 `https://github.com/EthanWangHaven/EthanWangHaven.github.io`

## 日常写笔记流程

### Step 1：新建文章

在 `content/blog/` 目录下新建 `.mdx` 文件，文件名用英文 + 连字符：

```
content/blog/your-article-name.mdx
```

### Step 2：编辑 Front Matter

```yaml
---
date: "2026-07-02T11:17:03+08:00"
draft: false
title: 文章标题
categories:
  - Blog
tags:
  - Next.js
  - Markdown
description: 文章简介，显示在卡片和详情页
---

这里开始写正文...
```

| 字段 | 含义 |
|------|------|
| `title` | 文章标题（支持中文） |
| `date` | 发布日期 |
| `draft` | `true` = 草稿（不显示），`false` = 发布 |
| `categories` | 分类，可多个 |
| `tags` | 标签，可多个 |
| `description` | 文章简介，无此字段时自动从正文生成摘要 |

### Step 3：本地预览

```powershell
npm run dev
```

浏览器打开 `http://localhost:3000/blog/your-article-name` 预览。

### Step 4：发布

```powershell
git add .
git commit -m "New post: 文章标题"
git push origin main
```

推送后 GitHub Actions 自动构建部署，等待 1-3 分钟即可在线访问。

1. **Git** — 用于拉取、推送代码
2. **Node.js 18.18+** — 运行 Next.js 开发服务器

```powershell
npm run dev
```

## 日常 Git 操作与多电脑同步

### 本地修改后推送

```powershell
git status
git add .
git commit -m "更新内容说明"
git push origin main
```

### 同步远程更新

```powershell
# 工作区干净时
git pull origin main

# 有本地修改时
git stash
git pull origin main
git stash pop
```

### 冲突处理

如果 `git stash pop` 后出现冲突，打开冲突文件手动解决（删除 `<<<<<<<`、`=======`、`>>>>>>>` 标记），然后：

```powershell
git add .
git commit -m "解决冲突"
git push origin main
```
