長音は前の仮名の母音を一拍延ばす規則で、間違えると意味が変わる。各段の長音ルールと例外を整理する。



长音含义：**把前面假名的元音拉长一拍，两个假名不要分开读。**

长音不是多出一个音节，而是把当前音节的元音"拖长"一拍，在节奏上占两拍。日语是拍节语言（mora-timed），长音少一拍或多一拍都会导致词义变化，所以必须读准。

---

## 一、基础规律：同行同段元音延长

最标准的规则——**什么段就加什么元音**。

### 1. あ段假名 + あ
あ段假名（あ、か、さ、た、な…な行あ列）后面加 **あ**。

例：ああ（a-a）、かあ（ka-a）、ばあ（ba-a）

### 2. い段假名 + い
い段假名（い、き、し、ち、に…な行い列）后面加 **い**。

例：いい（i-i）、きい（ki-i）、しい（shi-i）

### 3. う段假名 + う
う段假名（う、く、す、つ、ぬ…な行う列）后面加 **う**。

例：うう（u-u）、くう（ku-u）、すう（su-u）

> ✅ 以上3条属于最标准：什么段就加什么元音。

---

## 二、两条特殊例外（高频必考）

### 1. お段假名 + う
お段假名（お、こ、そ、と、ほ…お段）后面加长音，**不加お，而是加う**。

例：こう（kō）、そう（sō）、とう（tō）、ほう（hō）

> 虽然写的是「う」，但发音仍读お的元音 /o/ 拉长一拍，不要读成 /u/。

### 2. え段假名 + い
え段假名（え、け、せ、て、へ…え段）后面加长音，**不加え，而是加い**。

例：けい（kē）、せい（sē）、てい（tē）、へい（hē）

> 同理，写的是「い」，发音读え的元音 /e/ 拉长一拍，不要读成 /i/。

### 补充特例小知识
极少数单词中，え段后会加え（如「ええ」表示"是"），お段后会加お（如「おおきい」大的），属于第一种"相同元音重复"的情况，现代日语中数量很少。

---

## 三、片假名长音

片假名统一用长音符号 **ー** 表示，不需要再加元音假名。

例：
- コーヒー（kōhī，咖啡）
- スーパー（sūpā，超市）
- テレビ（无长音）

> ⚠️ 注意：外来语中有时长音会省略或缩短，如「スパゲッティ」原本应为「スパゲッティー」，现代口语中常被截短。

---

## 四、记忆速查表

| 假名所在段 | 长音添加字符 | 发音拉长为 |
| ---- | ---- | ---- |
| あ段 | あ | /a/ → /aː/ |
| い段 | い | /i/ → /iː/ |
| う段 | う | /u/ → /uː/ |
| え段 | い（少数：え） | /e/ → /eː/ |
| お段 | う（少数：お） | /o/ → /oː/ |

## 五、长音 vs 短音：词义对比（体会其重要性）

长音不是装饰，它会直接改变词义：

| 短音 | 意思 | 长音 | 意思 |
| ---- | ---- | ---- | ---- |
| き（ki） | 树 | きい（kī） | 黄色 |
| こ（ko） | 子 | こう（kō） | 路/功 |
| しゅ（shu） | 主 | しゅう（shū） | 周/集 |
| おば（oba） | 阿姨 | おばあ（obā） | 奶奶 |
| きかん（kikan） | 机关 | きかーん（kikān） | 期间（概念示例） |

读错一拍，意思就变了。初学者务必把长音读足。

---

## 六、易错点提醒

1. **别把「お+う」「え+い」读成 /ou/、/ei/**：它们是长音，是 /oː/、/eː/。
2. **动词变形中的「〜う」不是长音**：如「買おう（kaou）」是意志形，这里「う」是助动词，需断开读，不拉长。
3. **复合词中的元音相连不一定是长音**：如「まいあさ（毎朝）」，「い」与「あ」分属不同词，不连读。
4. **片假名的「ー」位置**：标在需要拉长的那个假名之后，如「コーヒー」第一拍「コ」拉长，第二拍「ヒ」也拉长。

---

## 一句话速记

> **段对段：あ段+あ、い段+い、う段+う；例外两兄弟：え段+い、お段+う；片假名一律加「ー」。**
