公开的课程和仓库大致分成互不往来的两派。一派从 DH（Denavit–Hartenberg）参数、雅可比、ROS 2 讲起，目标是让机械臂在固定工位上稳定抓取；另一派直接从示教数据、策略网络和 VLA（Vision-Language-Action）讲起，目标是让机械臂在开放环境里完成语言指定的任务。两派都叫“机械臂训练”，但输入、输出、评价方式和失败模式都不一样。这篇笔记先把边界画清楚，再给一个六阶段的顺序。后面五篇分别展开。

## 一、两条路线解决的不是同一个问题

路线 A 是传统控制。它假设物体、工位和流程基本固定，工程重心是把位姿算准、把轨迹规划得无碰撞、把控制器调稳。路线 B 是具身智能训练。它假设物体、位置和指令会变，工程重心是让策略从数据里学到可泛化的动作。

| 维度 | 路线 A：传统控制 | 路线 B：具身智能 |
|---|---|---|
| 任务假设 | 物体、工位、流程基本固定 | 物体、位置、指令可变 |
| 输入 | 目标位姿、CAD 或物体模型 | 图像、点云、语言指令 |
| 核心模型 | 运动学、动力学、规划、控制器 | 策略网络：BC（行为克隆）、RL（强化学习）或 VLA |
| 输出 | 关节轨迹或力矩指令 | 动作序列或末端增量 |
| 数据 | 标定数据、模型参数 | 示教数据、仿真交互、预训练模型 |
| 评价 | 成功率、节拍、重复精度 | 泛化、任务成功率、鲁棒性 |
| 主要工具 | ROS 2、MoveIt 2、Pinocchio | LeRobot、MuJoCo、Isaac Sim、PyTorch |
| 典型失败 | 标定漂移、奇异、碰撞 | 分布偏移、Sim2Real gap（仿真到现实差距）、推理延迟 |
| 部署方式 | 工位固定、可认证 | 场景开放、需要监控与回退 |

两者不是替代关系。VLA 输出动作后，仍要经过运动学求解、碰撞检查和限位保护；传统路线里的检测和 6D 位姿估计，本身也可能是学习模型。把两条路线对立起来，常见结果是：做学习的人不知道失败来自策略还是标定，做控制的人不知道物体一换为什么整条流程失效。

数据来源决定迭代速度：路线 A 改一个参数可以当天验证，路线 B 改一次数据分布往往要重新采集。

岗位差异也在这里。路线 A 更接近自动化集成：选型、标定、节拍、安全、维护；路线 B 更接近研究或算法工程：数据采集、训练、评测、部署监控。两者都需要运动学底座，但日常产出不同。

## 二、知识地图

需要补的知识可以分成五层：

1. **数学与几何**：齐次变换、旋转表示、雅可比、SVD（奇异值分解）与伪逆、拉格朗日动力学。
2. **本体理论**：正逆运动学、奇异点、动力学、轨迹规划、抓取。
3. **工具链**：ROS 2、URDF（统一机器人描述格式）、TF2（坐标变换库）、MoveIt 2、Pinocchio、仿真平台、相机标定。
4. **路线 A 或 B**：传统视觉抓取闭环，或模仿学习、强化学习、VLA。
5. **Sim2Real**：把仿真里的策略或参数迁到真机，处理接触、摩擦、时延和视觉差异。

每层的前置和产出不同。数学层的产出是能在代码里正确复合变换、判断奇异；本体层的产出是能解释一个抓取失败是 IK 无解、轨迹碰撞还是力矩不够；工具链层的产出是能让模型在仿真里动起来；路线层的产出是能独立完成一个闭环；Sim2Real 层的产出是能列出迁移前后的差异，而不是只跑一次成功视频。

顺序不必严格线性。工具链可以和数学并行，边跑仿真边补公式；但运动学必须先于 IK 和规划，动力学必须先于力控。数学也不需要先把整本线性代数读完，够用的集合是齐次变换、旋转表示、雅可比、SVD/伪逆和拉格朗日方程，遇到不懂的定义再回查。

| 层 | 前置与产出 | 常见卡点 |
|---|---|---|
| 数学与几何 | 前置：线性代数、微积分；产出：能正确复合变换、判断奇异 | 欧拉角顺序、四元数未归一化 |
| 本体理论 | 前置：数学；产出：能解释 IK 多解、轨迹是否动力学可行 | 把运动学可行当成动力学可行 |
| 工具链 | 前置：Linux、Python；产出：能在仿真里让机械臂动起来 | URDF 惯性缺失、TF 时间戳错误 |
| 路线 A/B | 前置：本体 + 工具链；产出：能完成一个闭环 | 误差归因、失败分支缺失 |
| Sim2Real | 前置：路线 + 真机；产出：能迁移并监控 | 接触、时延、视觉差异 |

一个具体顺序：先用手写 2R 理解变换和 IK，再用 Pinocchio 跑 6R，最后进 MoveIt 2。直接在 MoveIt 2 里调包，遇到规划失败时很难判断是模型、初值还是碰撞体的问题。

## 三、分阶段验收标准

验收标准写成“能做什么”，不写成“看完了什么”。阶段 0 是环境准备：Ubuntu、Python、ROS 2 或 MuJoCo 能跑通最小示例。这一步不算学习阶段，但没过这一关，后面的验收都无法执行。

下面六阶段对应 P1–P5：P1 位姿、运动学与雅可比；P2 动力学、力控与轨迹/抓取规划；P3 工具链；P4 路线 A；P5 路线 B。

| 阶段 | 能做什么 / 验收方式 | 文章 |
|---|---|---|
| 1 位姿与变换 | 变换、四元数插值、万向锁与双覆盖；手算并代码验证复合结果 | P1 |
| 2 运动学与 IK | 正运动学（FK）、逆运动学（IK）有解/多解/奇异判断；对 2R 写解析 IK，对 6R 跑数值 IK，能解释误差曲线 | P1 |
| 3 动力学与规划 | 2R 动力学、连续轨迹、RRT（快速扩展随机树）概率完备；能生成 2R 的力矩输入和五次多项式轨迹，解释跟踪误差 | P2 |
| 4 工具链与标定 | 仿真驱动、手眼标定；在仿真中跑通一次抓取示例，能解释标定误差 | P3 |
| 5 路线 A 闭环 | 检测、位姿、规划、执行串联；画出系统框图和状态机 | P4 |
| 6 路线 B 训练 | 示教采集、BC、Sim2Real 与域随机化；跑通 BC 训练示例，能解释闭环评估指标 | P5 |

阶段 5 和阶段 6 可以交换顺序，取决于目标是工业集成还是研究。阶段 4 不能跳过：没有标定和仿真，后面的失败无法归因。

## 四、和自动驾驶、LLM 推理的类比

**标定与坐标系。** 自动驾驶里的相机标定、雷达标定和坐标系树，与机械臂的手眼标定是同一类问题。区别在于机械臂工作空间小、精度要求高，标定误差会直接变成抓取偏差；整车标定的流程不能直接搬过来。

**瓶颈归因。** LLM 推理里先测 prefill 和 decode 的耗时占比，再决定优化哪一层；机械臂的误差也可以分层测量：标定误差、IK 误差、轨迹跟踪误差、接触误差。区别是机械臂的误差会在接触和闭环里放大，不能只看单步精度。评测也是同一思路：LLM 用固定评测集比较模型，机械臂用固定任务集比较策略；机械臂的评测集会被环境和物体位置影响，同一个策略换一个桌面高度，成功率就可能变化。

**控制。** PID 和 MPC（模型预测控制）的经验可以直接用在轨迹跟踪和阻抗控制。机械臂额外多了关节限位、奇异位形和接触约束，调参时不能只看阶跃响应。

**多模态模型。** VLA 可以看作视觉语言模型加一个动作头。区别是动作连续、有时序、受动力学约束，不能只按 token 生成的直觉去理解推理频率和动作平滑性。类比只用来建立直觉，不能替代定义。

## 五、常见误区

**直接上 VLA，跳过运动学。** 策略失败时无法判断是视觉没看懂、动作头输出不合理，还是 IK 无解。补运动学的成本，远低于在真机上反复试错。

**仿真跑通就等于真机可用。** 仿真里的接触、摩擦、传感器噪声和时延都与真机不同。没有域随机化和系统辨识，仿真成功率不能直接外推。

**把 MoveIt 2 当成机器人学的全部。** MoveIt 2 覆盖规划、碰撞检测和执行接口，不负责动力学建模、接触力控制和视觉标定。用它做 demo 很快，解释失败时不够。

**只看成功视频，不看失败模式。** 抓取任务的价值在于失败分支：没检测到、位姿偏了、规划失败、夹爪没夹住、抬起时滑落。每个分支都要有对应的检测和处理。

**一次标定长期使用。** 相机松动、碰撞、温度变化都会让手眼参数漂移。标定结果要有复核机制，至少记录标定日期和残差。

## 六、资源清单与用法

资源按阶段读，不必全读：

- **[Modern Robotics](https://modernrobotics.org/)**：运动学、动力学、规划的系统底座。前置是线性代数与微积分；先读 Ch.3–4（P1），Ch.8 对应 P2。
- **Craig, Introduction to Robotics**：经典运动学与动力学视角，作为 Modern Robotics 的对照。
- **[MIT 6.4210](https://manipulation.csail.mit.edu/)**：操作、抓取、感知与规划。前置是 Python 和基础机器人学；看讲义与作业，不追全部视频。
- **[ROS 2 Jazzy 文档](https://docs.ros.org/en/jazzy/)**：通信、TF、launch、ros2_control。按 P3 的片段查。
- **[MoveIt 2 文档](https://moveit.picknik.ai/)**：规划、碰撞、执行。先跑 tutorial，再读 API。
- **[Pinocchio](https://github.com/stack-of-tasks/pinocchio)**：快速 FK、IK、动力学。配合 P1、P2 的片段。
- **[MuJoCo](https://mujoco.readthedocs.io/)**：接触、RL、Sim2Real。先跑最小场景，再改模型。
- **[Isaac Sim](https://docs.isaacsim.omniverse.nvidia.com/)**：GPU 并行、域随机化。前置是 GPU 与 USD；需要时再上。
- **[LeRobot](https://huggingface.co/docs/lerobot)**：示教数据、策略训练。前置是 PyTorch；按 P5 的数据格式读。

论文按范式读：[RT-2](https://arxiv.org/abs/2307.15818) 和 [OpenVLA](https://arxiv.org/abs/2406.09246) 对应 VLA，[Diffusion Policy](https://arxiv.org/abs/2303.04137) 对应动作生成，[DAgger](https://arxiv.org/abs/1011.0686) 对应模仿学习的分布偏移，[PPO](https://arxiv.org/abs/1707.06347) 对应强化学习。先读摘要和方法，再决定是否复现。

课程和论文的取舍：课程给顺序，论文给边界。先把一门课程的最小作业做完，再读论文，否则容易把论文里的假设当成通用结论。资源不在多，在于和当前阶段匹配。P1 阶段只需要 Modern Robotics 的运动学章节和 Pinocchio 文档；到了 P5，再读 VLA 论文和 LeRobot 的数据格式，否则读不进去。
