日本語のアクセントは高低2種類の音高のみで、一語につき一つのピークしかない。5種類の調型と核心ルールを整理する。



## 一、基础概念

日语声调属于**高低型声调**（pitch accent），只有「低读、高读」2种音高，**一个假名占一拍**。

> 核心铁则：单词音调**只会出现1次高峰**，音调下降之后，就再也不会升高。

这一点和中文的"四声"完全不同——中文是每个字独立变调，日语是整个单词只有一条"高低曲线"，且只允许一个波峰。

- 低（L）：相对较低的音高
- 高（H）：相对较高的音高
- 高低是**相对**的，不是绝对音高，男声女声都能读。

---

## 二、5种调型详解

### ⓪调（零调 / 平板型）
第一个假名**低音**，从第2个假名开始后面**全部高音**，全程高平，没有下降。

> 音调走势：低 → 高 → 高 → 高……

例：あい（蓝）、あいうえお

⚠️ 注意：0调如果后面接助词，助词也跟着高音，不下降。

### ①调（头高型）
第一个假名**高音**，剩下后面所有假名**全部低音**，读完第一个立刻下滑。

> 音调走势：高 → 低 → 低 → 低……

例：あい①（愛）、ねこ①（猫）、はし①（筷子）

⚠️ ①调是唯一一个"第一拍就是高音"的调型，非常好辨认。

### ②调（中高型‑2）
第1假名低音、**第2假名高音**，剩下后面全部低音。

> 音调走势：低 → 高 → 低 → 低……

例：あおい②（蓝）、すこし②（一点点）、はし②（桥）

### ③调（中高型‑3）
第1假名低音，**第2‑3假名高音**，之后全部低音。

> 音调走势：低 → 高 → 高 → 低……

例：おいしい③（好吃）、あいたい③（想见）

### ④调（中高型‑4）
第1假名低音，**第2‑4假名高音**，之后全部低音。

> 音调走势：低 → 高 → 高 → 高 → 低……

例：はじめまして④（初次见面）、すみません④（对不起）

> 以此类推：⑤调、⑥调……规律相同——第1拍低，第2拍到第N拍高，第N+1拍开始低。

## 三、通用4条核心规律

### 1. 一拍对应一个假名
长音（ー、う等）、促音（っ）、拨音（ん）**都算一拍**，都会影响声调数字。

例：「コーヒー」共4拍，声调可能是③调。

### 2. 整词只能有一处高点
一旦降调，后面永远低音，**不会二次上升**。

这是日语声调最根本的规则——一条曲线，一个波峰，一旦下行就到底。

### 3. 除了①调，剩下所有调（0/2/3/4…）第一个假名都是低音
➡ 所以：只要不是①调，单词前两拍一定是「低‑高」，高低不一样。

> 这条规律极其重要：判断声调时，先听第一拍——
> - 第一拍高 → 一定是①调
> - 第一拍低 → 一定是0/2/3/4…调，再数高音持续到第几拍

### 4. 如果声调数字 = 单词假名总数，发音效果和0调一模一样

例：3拍词的③调、4拍词的④调，单独读时和0调听起来一样（都是"低→后面全高"）。

**区别体现在接助词时**：
- 0调 + 助词 → 助词继续高音
- ③调(3拍) + 助词 → 助词下降为低音

这是0调和"尾调"最关键的区分点。

## 四、快速记忆对照表

| 声调 | 第1拍 | 高音区间 | 之后所有拍 | 助词（单独词后） |
| ---- | ---- | ---- | ---- | ---- |
| ⓪调 | 低 | 第2拍~末尾 | 一直高音 | 高（继续高） |
| ①调 | 高 | 仅第1拍 | 低 | 低 |
| ②调 | 低 | 第2拍 | 低 | 低 |
| ③调 | 低 | 第2‑3拍 | 低 | 低 |
| ④调 | 低 | 第2‑4拍 | 低 | 低 |

> 核心区分：只有⓪调和"数字=拍数"的调在单独读时听不出区别，**接助词才能区分**。

## 五、声调的功能：区分同音词

日语声调最大的作用是**区分同音词**，读错声调=说错词：

| 假名 | 声调 | 意思 |
| ---- | ---- | ---- |
| はし | ① | 筷子 |
| はし | ② | 桥 |
| はし | ⓪ | 端（边缘） |
| あめ | ① | 雨 |
| あめ | ⓪ | 糖 |
| じしん | ① | 地震 |
| じしん | ⓪ | 自信 |

声调错了，日本人会理解成另一个词，或者听不懂——这是初学者最容易被忽视但最影响交流的点。

## 六、声调变化（重要进阶）

声调不是固定的，会随**复合词、动词变形、接助词**而变化：

### 1. 名词 + 助词
- 0调词 + 助词 → 助词保持高音
- ①/②/③…调词 + 助词 → 助词一律降为低音

### 2. 复合词（名词+名词）
复合后声调通常会重新计算，往往落在第二个词的首拍。

例：「あめ（①）+ あめ（①）」→「あめあめ」可能变成⓪或别的调，需查词典。

### 3. 动词变形
动词变形后声调会移动，如「食べる②」→「食べない②」声调位置可能变化。

---

## 七、常见易错点

1. **把日语声调当中文四声读**：日语只有高低，没有升降调曲线。
2. **忽视促音、长音、拨音的拍数**：少算一拍，声调数字就判断错。
3. **0调和尾调分不清**：单独读时听起来一样，必须接助词才能区分。
4. **复合词声调不查词典乱猜**：复合词声调规则复杂，建议查词典确认。
5. **以为声调可忽略**：实际会影响词义和自然度，是地道日语的关键。

---

## 一句话速记

> **高低只有两档，全词只有一个波峰；非①调第一拍必低，高音持续到第N拍后下降；0调+助词继续高，其余+助词都降。**
